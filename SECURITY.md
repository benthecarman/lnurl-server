# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in `lnurl-server`, please report it
privately by emailing [benthecarman@live.com](mailto:benthecarman@live.com).

Please include a description of the vulnerability, steps to reproduce it, its
potential impact, and any suggested remediation. Do not open a public issue or
disclose the vulnerability publicly until it has been investigated and a fix
has been made available.

You should receive an acknowledgment within seven days. After reviewing the
report, the maintainer will share an assessment and, when appropriate, a plan
for remediation and coordinated disclosure.
